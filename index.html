Fundamentación Matemática: ¿Qué es una Antiderivada o Primitiva?

Definición Formal e Operación Inversa

En el cálculo diferencial aprendimos a hallar la derivada f'(x) de una función conocida. El cálculo integral plantea el problema inverso: dada una función f(x), encontrar una función F(x) cuya derivada sea exactamente f(x).

A F(x) se le denomina función primitiva o antiderivada de f(x) en un intervalo I si se cumple:

F'(x) = f(x)  ∀ x ∈ I
Notación: ∫ f(x) dx = F(x) + C

Significado de la Constante C (Familia de Curvas)

Observa que las funciones F1(x) = x2 + 3, F2(x) = x2 y F3(x) = x2 − 2 tienen todas exactamente la misma derivada: f(x) = 2x, porque la derivada de cualquier número constante es cero.

Por ello, al integrar no obtenemos una única función, sino una familia infinita de primitivas desplazadas verticalmente entre sí por una constante arbitraria C ∈ ℝ.

∫ 2x dx = x2 + C
Cada valor de C genera una parábola paralela en el plano.

Representación Visual: Proceso Inverso y Familia de Antiderivadas F(x) = x2 + C

Todas las curvas tienen idéntica pendiente en cada punto x; solo difieren en su desplazamiento vertical C.

Reglas Fundamentales de Integración Indefinida

1. Regla de la Constante

La integral de una constante real k respecto a x es igual al producto de dicha constante por la variable de integración, más la constante C.

∫ k dx = kx + C
Caso especial (k = 1): ∫ 1 dx = ∫ dx = x + C
Ejemplo: ∫ −7 dx = −7x + C

2. Regla de la Potencia (Monomios)

Para integrar cualquier monomio de la forma axn (con exponente entero positivo, negativo o fraccionario, siempre que n ≠ −1):

∫ axn dx = an + 1xn + 1 + C
Si el monomio tiene radicales o potencias en el denominador, primero se reescribe como potencia xn.
Propiedades previas: 1xm = x−m  |  q√xp = xp/q
5 Ejemplos Guiados Paso a Paso (Monomios: Enteros, Negativos y Fraccionarios)

Ejemplo 1: Exponente Entero Positivo

Calcula: ∫ 12x3 dx
1. Aplicamos regla de potencia (n = 3):
= 123 + 1x3 + 1 + C = 124x4 + C
= 3x4 + C

Ejemplo 2: Exponente Negativo

Calcula: ∫ 6x−4 dx
1. Sumamos 1 al exponente (n = −4):
= 6−4 + 1x−4 + 1 + C = 6−3x−3 + C
2. Simplificamos y pasamos a exponente positivo:
= −2x−3 + C = −2x3 + C

Ejemplo 3: Variable en el Denominador

Calcula: ∫ 5x2 dx
1. Subimos la potencia con signo negativo: ∫ 5x−2 dx
2. Integramos (n = −2): 5−2 + 1x−2 + 1 + C = 5−1x−1 + C
= −5x−1 + C = −5x + C

Ejemplo 4: Exponente Fraccionario

Calcula: ∫ 4x1/3 dx
1. Sumamos 1 al exponente (13 + 1 = 43):
= 44/3x4/3 + C = 4 · 34x4/3 + C
= 3x4/3 + C

Ejemplo 5: Monomio con Radical (∫ 3√x dx)

1. Transformamos el radical a exponente fraccionario: ∫ 3x1/2 dx
2. Aplicamos regla de potencia (12 + 1 = 32):  33/2x3/2 + C = 3 · 23x3/2 + C
= 2x3/2 + C = 2√x3 + C
